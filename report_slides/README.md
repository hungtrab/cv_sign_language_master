# Visualization, Slides & Report — session summary

This folder (plus `asl_pipeline/visualize_*.py` and `report/`) contains everything
produced to answer one question for the team: **does a "smarter" representation
(hand-crop, landmarks, enhancement) actually improve ASL alphabet recognition, or
does it just add a new way to fail?** Read this before re-running anything or
presenting the deck — it explains where each artifact came from and the one
metric gotcha that affects every number in the report.

## What's in here

| File | What it is |
|---|---|
| `Slide_ASL.tex` / `Slide_ASL.pdf` | Vietnamese slide deck, HUST beamer theme (`pdflatex` only — see below) |
| `Slide_ASL_EN.pptx` | English PowerPoint version of the same deck, image-heavy, built with `build_pptx.py` |
| `build_pptx.py` | Script that generates `Slide_ASL_EN.pptx` — edit this, not the pptx directly, then re-run |
| `PRESENTATION_PLAN.md` | Slide-by-slide speaking notes, timing, and anticipated Q&A |
| `photos/` | Curated figure subset embedded in both the slides and `report/asl_report.tex` |
| `beamerthemeHUST.sty`, `images/` | HUST beamer theme assets (blue/169 variant only — kept minimal) |

The full LaTeX report lives in `../report/asl_report.tex` (`asl_report.pdf`).
It reuses the same `photos/` folder so the report and slides never drift apart.

## Where the figures came from

All figures in `photos/` are generated by scripts in `asl_pipeline/`, run on the
remote training server (not locally — the dataset and trained weights live there):

| Script | Produces |
|---|---|
| `asl_pipeline/visualize_steps.py` | Per-pipeline step grids: raw → representation → recognizer input → top-3 prediction |
| `asl_pipeline/visualize_cnn_internals.py` | ResNet18 layer activation maps + Grad-CAM (`cnn_internals_*.png`) |
| `asl_pipeline/visualize_grid.py` | Report-style grids: `grid_representation.png`, `grid_recognizer.png`, `compare_*.png` |
| `asl_pipeline/visualize_embedding.py` | UMAP/t-SNE plots: `embedding_landmarks_by_class.png`, `embedding_cnn_by_class.png`, `embedding_representation_shift.png` |

To regenerate or extend any figure: SSH into the training server, `cd` into the
project's `asl_pipeline/`, `source .../activate asl_env`, run the script with
`--help` for options, then `scp` the PNG back into this `photos/` folder and
re-run `pdflatex` / `build_pptx.py`.

## The one thing to know before trusting any accuracy number

`evaluate.py`'s standard `clean_accuracy` is computed **only over images where a
hand was detected** — it silently drops "Unknown" (no-hand-detected) images from
both the numerator and denominator. This makes MediaPipe-based pipelines look
much better than they actually are. The real end-to-end number is the
`accuracy_with_unknown_as_wrong` field already present in every
`outputs/metrics/<pipeline>_metrics.json`, but it is **not** in
`outputs/tables/pipeline_summary.csv` yet. Concretely:

- `mediapipe_crop_vit` reports 98.5% clean accuracy, but its real accuracy is
  **81.15%** (2110/2600) — see the Case Study slide/section.
- `mediapipe_crop_resnet18` reports 88.6%, real accuracy is **69.3%**.

If you add a new pipeline or re-run evaluation, compute and report both numbers.

## Pipeline naming: 13 unique pipelines, not 17

The first evaluation sweep accidentally registered 4 pipelines under two names
each (identical representation + recognizer, just a copy-paste in
`registry.py`'s `register_defaults()`). These duplicates were deleted from the
server (`outputs/predictions`, `outputs/metrics`, `outputs/figures`,
`outputs/runs`, `outputs/visualizations`) and `pipeline_summary.csv` was
regenerated. If you see any of these four names anywhere, they're stale —
use the name on the right instead:

| Removed (duplicate) | Keep instead |
|---|---|
| `mediapipe_resnet18` | `mediapipe_crop_resnet18` |
| `landmark_mlp` | `mediapipe_landmarks_mlp` |
| `no_enhance_resnet18` | `raw_resnet18` |
| `raw_hf` | `raw_siglip` |

The 13 surviving pipelines: `raw_resnet18`, `raw_siglip`,
`mediapipe_crop_resnet18`, `mediapipe_crop_vit`, `mediapipe_landmarks_mlp`,
`mediapipe_landmarks_svm`, `mediapipe_landmarks_rf`,
`enhancement_{clahe,gamma,sharpen,denoise}_resnet18`,
`enhancement_{clahe,gamma}_vit`.

## How to (re)build everything

```bash
# Vietnamese LaTeX slides — MUST use pdflatex, NOT xelatex
# (the `vietnam` package loses all diacritics under xelatex)
cd report_slides
pdflatex Slide_ASL.tex && pdflatex Slide_ASL.tex   # twice for TOC/refs

# English PowerPoint deck
python3 build_pptx.py   # needs: pip install python-pptx pillow

# LaTeX report
cd ../report
pdflatex asl_report.tex && pdflatex asl_report.tex
```

Optional QA without opening PowerPoint: `pip install "markitdown[pptx]"` then
`python3 -c "from markitdown import MarkItDown; print(MarkItDown().convert('report_slides/Slide_ASL_EN.pptx').text_content)"`
to read back every slide's text and confirm nothing is missing/broken.
